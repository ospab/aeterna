# Оболочка и утилиты

В консоли работает **plum** — оболочка с синтаксисом в стиле Bourne shell. Сейчас оболочка и
утилиты выполняются внутри ядра; программы, установленные из пакетов, запускаются отдельными
процессами в ring 3.

## Синтаксис

| Возможность | Пример |
|---|---|
| Переменные | `x=5; echo $x ${x:-default} ${#x}` |
| Арифметика | `echo $((x * 2))`, `((x++))`, `let y=x+1` |
| Подстановка команд | `echo "сегодня: $(date)"`, обратные кавычки |
| Конвейеры и списки | `ls / \| grep etc`, `a && b`, `a \|\| b`, `a; b` |
| Перенаправления | `> file`, `>> file`, `< file`, `2> file`, `2>&1`, `&> file` |
| Управляющие конструкции | `if`, `for`, `while`, `until`, `case`, `break`, `continue` |
| Функции | `greet() { echo "hi $1"; }; greet ospab` |
| Шаблоны, кавычки | `ls /etc/*.conf`, `'одинарные'`, `"двойные $x"`, `~` |
| Скрипты | `bash script.sh args`, `./script.sh`, `source file`, `bash -c '...'` |

Встроенные команды: `cd`, `pwd`, `export`, `unset`, `set`, `env`, `alias`, `source`,
`type`/`which`, `test`/`[`/`[[`, `read`, `eval`, `shift`, `echo`, `exit`.

Пока нет: фоновых задач (`&` выполняется на переднем плане), here-документов, массивов. Части
конвейера выполняются по очереди, а не одновременно.

## Команды

- Файлы: `ls`, `cat`, `touch`, `mkdir`, `rmdir`, `rm`, `cp`, `mv`, `stat`, `du`, `df`, `tree`,
  `find`, `tee`, `write`, `sync`.
- Текст: `grep` (регулярные выражения, `-E -F -i -v -n -c -l -o -w -x -r -q`), `head`, `tail`, `wc`,
  `sort`, `uniq`, `cut`, `tr`, `rev`, `nl`, `xxd`, `diff`, `awk` (подмножество), `seq`, `printf`,
  `xargs`, `yes`.
- Система: `uname`, `date`, `uptime`, `hostname`, `free`, `lsmem`, `ps`, `top`, `kill`, `dmesg`,
  `lspci`, `shutdown`, `reboot`.
- Диски: `lsblk`, `fdisk -l`, `mkfs`, `mount`, `install`.
- Сеть: `ip`, `ifconfig`, `ping`, `nslookup`, `curl`, `traceroute`, `netstat`, `ntpdate`, `ostp`.
  См. [Сеть и OSTP](networking.md).
- Приложения: `grape` (текстовый редактор), `tomato` (пакеты), `doom`, `soundtest`, `vol`, `clip`.

`help` показывает всё; `help <команда>` объясняет одну команду.

## Программы из пакетов

Команда, которой нет среди встроенных, ищется по пути или в `$PATH` (по умолчанию
`/usr/bin:/bin`). ELF-файлы запускаются как процессы в ring 3: их вывод идёт на экран или в
конвейер, `$?` содержит код выхода, а Ctrl+C просит ядро их остановить. См. [Пакеты](packages.md).

## Клавиши

| Клавиша | Действие |
|---|---|
| Tab | дополнение команд и путей |
| ↑ / ↓ | история |
| Ctrl+A / Ctrl+E | начало / конец строки |
| Ctrl+U / Ctrl+K / Ctrl+W | удалить до начала / до конца / предыдущее слово |
| Ctrl+L | очистить экран |
| Ctrl+C | отменить строку или прервать выполняемую команду |
| Ctrl+V | вставить буфер обмена хоста (VMware) |

## Буфер обмена и последовательная консоль

В VMware **Ctrl+V** вставляет в консоль буфер обмена Windows (копирование и вставка должны быть
разрешены в настройках Guest Isolation виртуальной машины). Переносы строк во вставленном тексте
превращаются в пробелы, поэтому вставленная ссылка никогда не запускает команду сама.

```
# clip                          напечатать буфер обмена хоста
# clip set hello                положить текст в буфер обмена хоста
# ostp import $(clip)           использовать буфер в команде
```

Консоль принимает ввод и с первого последовательного порта. В VMware добавьте последовательный
порт через именованный канал (например, `\\.\pipe\ospab`), подключите к нему PuTTY как к
последовательной линии и вставляйте правой кнопкой мыши. В QEMU используйте `-serial stdio`.

## Время

При загрузке часы берутся из CMOS RTC и уточняются по NTP (`ntpdate`, а также один раз при старте
консоли, если сеть поднята). Если RTC хранит местное время, как Windows и VMware, сдвиг
определяется при первой синхронизации по NTP и сохраняется в `/etc/rtc_offset`. Часовой пояс для
отображения берётся из `/etc/timezone`, например `UTC+3`.

`date -e` печатает секунды от эпохи ospab, 2012-08-09 00:00:00 UTC; `date --unix` — время Unix.
