# beeb: эмулятор BBC Micro

`beeb` эмулирует BBC Micro Model B (32 КБ, MOS 1.20). Он написан с нуля для ospab.os. Это
программа кольца 3: процессор, видео, VIA и диск реализованы в крейте `beeb-core`
(`apps/beeb-core`), оболочка вокруг него — `apps/beeb`.

## Правовая оговорка

В ospab.os **нет** ни одного ROM от BBC и ни одной игры. ROM MOS и образы дисков защищены
авторским правом. Вы приносите собственные копии, например снятые с машины, которой владеете.
Ничего подобного нет ни в репозитории, ни в ISO, ни в репозитории пакетов. `.gitignore` проекта
исключает `*.rom` и `*.ssd`, чтобы их не закоммитить случайно.

## Что нужно

| Файл | Размер | Куда |
|---|---|---|
| ROM BBC MOS 1.20, обычно `os12.rom` | ровно 16384 байта | `/usr/share/beeb/os12.rom` или любой путь через `-mos` |
| ROM BBC BASIC (необязательно, нужен многим дискам) | 16384 байта | любой путь, через `-basic` или `-rom` |
| образ односторонней дискеты DFS, `.ssd` | до 200 КБ (80 дорожек) | любой путь в командной строке |

Файлы попадают в систему через `curl` с веб-сервера на вашем ПК (сеть QEMU user:
`http://10.0.2.2:8000/...`) или копированием на установленный диск.

## Запуск

```
# tomato -U beeb.tmt
# curl -o /usr/share/beeb/os12.rom http://10.0.2.2:8000/os12.rom
# curl -o /tmp/disc.ssd http://10.0.2.2:8000/disc.ssd
# beeb -mos /usr/share/beeb/os12.rom /tmp/disc.ssd
```

```
beeb [-mos os12.rom] [-basic basic.rom] [-rom СЛОТ файл.rom] [-scale N] [disc.ssd]
```

- `-mos ПУТЬ`: ROM MOS. Если файла нет, программа сообщает об этом и завершается.
- `-basic ПУТЬ`: ROM BBC BASIC в слот 15. Без языкового ROM MOS останавливается на
  `Language?`. Диски, у которых загрузчик — программа на BASIC (Elite такой), без него не
  запустятся.
- `-rom N ПУТЬ`: любой другой ROM в слот N (0..13; слот 14 занят встроенной дисковой системой).
- `-scale N`: масштаб пикселя по горизонтали. По умолчанию — наибольший целый, который
  помещается. По вертикали масштаб вдвое больше, если помещается (пиксель BBC примерно вдвое
  выше, чем шире, на мониторе 4:3), иначе 1.
- `disc.ssd`: вставляется в привод 0 и загружается как по SHIFT+BREAK (файл `!BOOT` выполняется
  по `*OPT 4` диска).

Значения по умолчанию можно записать в `/etc/beeb.conf`, по одному `ключ=значение` в строке,
`#` — комментарий:

```
mos=/usr/share/beeb/os12.rom
disc=/home/games/elite.ssd
basic=/usr/share/beeb/basic2.rom
rom3=/usr/share/beeb/other.rom
scale=1
```

Картинка 640x256, по центру экрана, чёрные поля, 50 кадров в секунду. Пока `beeb` работает,
он владеет экраном и клавиатурой (см. [ABI системных вызовов](syscall-abi.md), «Экран,
клавиатура, часы»). После выхода консоль возвращается.

## Клавиши

| Клавиша ПК | Действие |
|---|---|
| Esc | BBC ESCAPE |
| F12 | выйти из эмулятора |
| F11 | сброс (машина перезапускается и снова загружает диск) |
| Ctrl+C | завершить программу (ядро возвращает экран) |

Остальное — по положению: клавиша ПК на месте клавиши BBC.

| ПК | BBC |
|---|---|
| буквы, цифры, `-`, `;`, `,`, `.`, `/`, `[`, `]`, `\`, пробел, Tab, Enter | та же клавиша |
| `=` | `^` |
| `'` | `:` |
| `` ` `` | `@` |
| Insert | клавиша фунта/подчёркивания |
| Backspace, Delete | DELETE |
| End | COPY |
| стрелки | клавиши курсора |
| Caps Lock | CAPS LOCK |
| Scroll Lock | SHIFT LOCK |
| левый и правый Shift, левый и правый Ctrl | SHIFT, CTRL |
| F1 … F10 | f0 … f9 |

Символы с Shift — как на клавиатуре BBC, а не ПК (Shift+2 даёт `"`). У BBC нет клавиш для `Alt`,
`Home`, `PgUp`, `PgDn` и цифровой панели; они ничего не делают.

Клавиши Elite: S и X (тангаж), `<` и `>` (крен; на ПК `,` и `.` с Shift), пробел (скорость
больше), `?` (скорость меньше; на ПК `/` с Shift), A (огонь), TAB (гиперпрыжок), функциональные
клавиши f0…f9 для видов и меню (на ПК F1…F10).

## Что эмулируется

- Процессор 6502: документированные коды и часто используемые недокументированные, число
  тактов, десятичный режим, IRQ и NMI. Частота 2 МГц.
- Карта памяти Model B: 32 КБ ОЗУ, 16 слотов ROM по `&8000`, MOS по `&C000`, страница ввода-вывода
  `&FE00`.
- 6845 CRTC и видео-ULA, вычисляются построчно, поэтому изменения посреди кадра (разделённый
  экран Elite: режим 4 сверху, режим 5 для приборной панели) показываются верно. Режимы 0–6 и
  простой телетекст (режим 7).
- Системный VIA (таймеры, прерывания, матрица клавиатуры, адресуемая защёлка) и таймеры
  пользовательского VIA.
- Диск: образы `.ssd` читаются высокоуровневой DFS: вызовы файловой системы (OSFILE, OSFIND,
  OSARGS, OSBGET, OSBPUT, OSGBPB, `*RUN`, `*LOAD`, `*EXEC`) обрабатывает сам эмулятор, поэтому
  ни ROM DFS, ни контроллер 8271 не нужны. Файлы, записанные программой, остаются в памяти и
  пропадают при выходе; образ на диске не меняется.

Не эмулируется: звук (SN76489), контроллер 8271, второй процессор, Econet, АЦП и джойстик,
лента, речь, порт принтера.

## Ограничения

- Только с ROM MOS машина запускается и печатает `BBC Computer 32K` и `Language?`: запускать
  нечего. С ROM BASIC (`-basic`) появляется приглашение `>` и запускаются диски с загрузчиком на
  BASIC.
- Скорость зависит от хоста. В QEMU без KVM эмулятор может не успевать за 50 Гц; тогда он
  теряет время, а не догоняет.
- Изменение стартового адреса экрана посреди кадра работает; чересстрочная развёртка и курсор
  6845 не рисуются.

## Исходники

- `apps/beeb-core/src/cpu.rs`: 6502.
- `apps/beeb-core/src/machine.rs`: карта памяти, SHEILA, связующий код.
- `apps/beeb-core/src/video.rs`, `via.rs`, `keyboard.rs`, `disc.rs`: части машины.
- `apps/beeb/src/main.rs`: оболочка (аргументы, файлы, клавиши, фреймбуфер, темп 50 Гц).
- `apps/gfxtest`: тестовая программа для вызовов экрана, raw-клавиатуры и часов.
