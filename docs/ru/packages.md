# Пакеты

## Работа с tomato

```
# tomato -Sy              скачать индекс пакетов и проверить его подпись
# tomato -Ss [текст]      искать по синхронизированному индексу
# tomato -S calc          установить пакет с зависимостями
# tomato -Syu             синхронизировать и обновить установленные пакеты
# tomato -Q               установленные пакеты (-Qi сведения, -Ql файлы)
# tomato -R calc          удалить пакет (отказ, пока от него зависит другой пакет)
# tomato -U file.tmt      установить локальный файл пакета
```

Репозиторий по умолчанию — `https://tmt.ospab.org/x86_64/`. Чтобы использовать другой, добавьте
строки `repo=<url>` в `/etc/tomato.conf` (для локальных тестов разрешён `http://`).

## Как защищены пакеты

- Индекс подписан Ed25519. Публичный ключ вшит в систему (`userland/tomato/repo_key.pub`); индекс
  с неверной подписью отвергается, а сохранённый индекс перепроверяется при каждом использовании.
- Размер и SHA-256 каждого пакета записаны в подписанном индексе и проверяются до установки.
- `tomato -R` удаляет только те файлы, которые установил пакет.

Известное ограничение: защиты от подсовывания старого, но честно подписанного индекса пока нет.

## Формат .tmt

Файл `.tmt` — это пакет: заголовок с именем, версией, архитектурой, зависимостями и описанием, за
ним файлы с путями назначения и контрольными суммами. Собирается хост-утилитой `tmt` или внутри
системы командой `tomato --tmt pack`.

## Как написать программу

Программы — бинарники Rust без `std` для цели `x86_64-unknown-oos`, слинкованные с рантаймом
**liboos** (`_start`, системные вызовы, куча, `print!`). SDK — рабочее пространство `apps/`;
`apps/README.md` по шагам объясняет, как сделать новую программу. Примеры: `hello-tmt`, `cowsay`,
`calc`.

Манифест пакета (`apps/pkg/calc.toml`):

```toml
name = "calc"
version = "0.1.0"
description = "Command-line calculator"
arch = "x86_64"
depends = []

[[files]]
src = "../target/x86_64-unknown-oos/release/calc"
dest = "/usr/bin/calc"
```

Поднимайте `version` при каждом изменении: опубликованные пакеты кешируются как неизменяемые.

## Сборка и публикация репозитория

Windows (PowerShell 7):

```
.\apps\build.ps1 -Repo D:\ospab-projects\tmt-repo -Upload user@server
```

Git Bash, WSL или Linux:

```
bash apps/build.sh repo /path/to/tmt-repo
```

Оба варианта собирают программы, упаковывают их, добавляют в репозиторий, строят индекс,
подписывают его ключом `%USERPROFILE%\.ospab\tmt.key` (в WSL задайте
`USERPROFILE=/mnt/c/Users/<вы>`) и проверяют подпись ключом, вшитым в систему. Выгружайте сначала
пакеты, потом `index`, последним `index.sig`.

Настройка сервера (nginx, HTTPS через certbot) описана в
[tools/tmt/deploy/README.md](../../tools/tmt/deploy/README.md). Сделайте резервную копию
приватного ключа: если он потеряется, придётся создать новую пару ключей и выпустить новый образ
системы.
