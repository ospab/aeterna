# Документация ospab.os

Основной язык документации — английский; русская версия — перевод и может отставать.
[English version](../en/README.md).

## Пользователю

- [Первые шаги](getting-started.md): запуск ospab.os в VMware или QEMU, первые команды.
- [Установка](installation.md): установка на диск, установка рядом с Windows и Linux, загрузка.
- [Оболочка и утилиты](shell.md): оболочка `plum`, утилиты, клавиши, буфер обмена, последовательная консоль.
- [Пакеты](packages.md): `tomato`, подписанный репозиторий, как написать и упаковать программу.
- [Сеть и OSTP](networking.md): адреса, `curl`, DNS, время, клиент OSTP.
- [Оборудование](hardware.md): поддерживаемые устройства и рекомендуемые настройки ВМ.

## Разработчику

- [Сборка](building.md): инструменты, цели сборки, ISO и образы дисков, автотест.
- [Архитектура](architecture.md): загрузка, кольца, память, планировщик, объекты ядра и IPC.

## Обозначения

- Команды, которые вы вводите в ospab.os, показаны после приглашения `#`; команды для вашего ПК —
  без него.
- «Ring 0» — ядро, «ring 3» — пользовательские программы. «ISO N» или «сборка #N» — номер,
  который показывает `uname -a`.
