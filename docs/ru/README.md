## Обозначения

- Команды, которые вы вводите в ospab.os, показаны после приглашения `#`; команды для вашего ПК —
  без него.
- «Ring 0» — ядро, «ring 3» — пользовательские программы. «ISO N» или «сборка #N» — номер,
  который показывает `uname -a`.
