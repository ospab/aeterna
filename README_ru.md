**ospab.os** — закрытая, вертикально интегрированная операционная система, написанная с нуля на
Rust. Её ядро называется **AETERNA**. Система не стремится к совместимости с Linux или Windows:
загрузчик, ядро, драйверы, сетевой стек, оболочка, пакетный менеджер и утилиты пишутся вместе
и задуманы как единое целое. ОС входит в экосистему ospab и поддерживает протокол
[OSTP](https://github.com/ospab/ostp) на уровне системы.

> **Статус: исследовательская система в процессе переделки.** Ядро переходит от монолита
> с одним адресным пространством к настоящему микроядру. Процессы в ring 3, объекты ядра,
> права доступа и IPC уже работают; большинство драйверов и оболочка пока выполняются внутри
> ядра. План — в [ROADMAP.md](ROADMAP.md), честное состояние кода — в [AUDIT.md](AUDIT.md).

## Что работает сейчас

| Область | Состояние |
|---|---|
| Загрузка | Свой UEFI-загрузчик **ospab-boot** (меню, чтение FAT и ISO9660); Limine для гибридного ISO с BIOS и UEFI |
| Установка | Полноэкранный установщик: стереть диск или **установить рядом** с Windows и Linux в существующий EFI-раздел |
| Процессор | GDT/TSS, IDT, таймер APIC, вытесняющий планировщик, свой стек ядра у каждой задачи, XSAVE (состояние AVX) |
| Память | Битовый аллокатор кадров, 4-уровневые таблицы страниц, адресное пространство у каждого процесса, NX, SMEP/SMAP |
| Ring 3 | ELF-программы для цели `x86_64-unknown-oos` с рантаймом **liboos** |
| Микроядро | Объекты ядра, таблицы дескрипторов с правами, синхронный IPC, уведомления |
| Диски | ATA PIO, AHCI, NVMe, virtio-blk; GPT; сохранение изменяемого слоя файловой системы |
| Сеть | e1000, RTL8139/8169, virtio-net, AMD PCnet (vlance в VMware), vmxnet3; IPv4, TCP, UDP, DHCP, DNS, NTP, клиент TLS 1.3 |
| OSTP | Встроенный клиент: ссылки, подписки, транспорты UDP и UoT |
| Звук | Intel HDA, AC97, ES1371/ES1373 (VMware), ES1370 |
| Ввод и видео | Клавиатура и мышь PS/2 и USB (xHCI), мышь VMware, фреймбуфер UEFI, VMware SVGA II |
| Связь с хостом | Буфер обмена VMware (Ctrl+V, `clip`), ввод в консоль через последовательный порт |
| Оболочка | `plum`: переменные, конвейеры, перенаправления, управляющие конструкции, функции, скрипты; утилиты; Ctrl+C |
| Пакеты | `tomato` с подписанным репозиторием **tmt.ospab.org**; SDK для своих программ |
| Питание и время | Выключение и перезагрузка через ACPI; системные часы считают от эпохи ospab, 2012-08-09 |

Всё перечисленное, кроме программ в ring 3, пока работает в ring 0. Вынос драйверов, сетевого
стека и консоли в изолированные серверы — следующий этап дорожной карты.

## Быстрый старт

1. Скачайте ISO из релизов или соберите сами (см. ниже).
2. В VMware Workstation создайте ВМ: **Other 64-bit**, прошивка **UEFI** (Secure Boot выключен),
   USB-контроллер **USB 3.x**. Подключите ISO и загрузитесь.
3. В консоли попробуйте `help`, `tutor`, `uname -a`, `tomato -Sy`, `install`.

Подробно: [docs/ru/getting-started.md](docs/ru/getting-started.md).

## Сборка

Нужны Rust nightly с `rust-src`; для ISO ещё `xorriso`, `mtools` и `mkfs.vfat`
(на Windows ISO собирается из WSL).

```bash
./build.sh kernel   # только ядро, быстрая проверка компиляции
./build.sh          # загрузочный гибридный ISO в isos/ospab-os-v2-N.iso
./build.sh image    # образ GPT-диска с ospab-boot, без WSL
```

Номер сборки `N` виден в `uname -a`. Подробно: [docs/ru/building.md](docs/ru/building.md).

## Структура проекта

```
arch/x86_64/   настройка процессора, прерывания, TSS, фреймбуфер, serial, клавиатура, мышь, протоколы загрузки
boot/          UEFI-загрузчик ospab-boot и его конфиг
core/          планировщик, системные вызовы, объекты ядра, IPC, загрузчик ELF
mm/            аллокатор кадров, таблицы страниц, копирование из ring 3, куча
drivers/       диски, звук, графика, интеграция с VMware
net/           драйверы сетевых карт, сетевой стек, TLS, OSTP
vfs/           VFS, RamFS, корень copy-on-write, синхронизация с диском
src/           вход в ядро, консоль, установщик, время, оболочка и утилиты
user/          рантайм liboos и встроенные программы ring 3
apps/          рабочее пространство SDK для программ в пакетах
gui/           программная библиотека интерфейса (в работе)
tools/         mkimage, упаковщик tmt и инструменты репозитория
docs/          документация на английском (docs/en) и русском (docs/ru)
```
